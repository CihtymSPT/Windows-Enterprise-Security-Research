# RE-001 — Windows PowerShell Logging & Detection

**Status:** Planned  
**Research Area:** Endpoint Telemetry / Detection Engineering  
**Platform:** Windows 11  
**ATT&CK Technique:** T1059.001 — PowerShell

## Research Question

How does enhanced PowerShell logging and endpoint telemetry affect the
visibility of PowerShell activity compared with a baseline Windows
configuration?

## Objective

This experiment will evaluate the telemetry generated by PowerShell activity
under different Windows logging configurations.

The experiment will compare a baseline Windows configuration with an enhanced
telemetry configuration using PowerShell logging and Sysmon.

The objective is to determine which telemetry sources provide useful
visibility for detecting suspicious PowerShell behavior and how additional
logging changes that visibility.

## Environment

The experiment is planned to use:

- Domain-joined Windows 11 endpoint
- Windows Security auditing
- PowerShell Operational logging
- PowerShell Script Block Logging
- Sysmon
- Microsoft Defender

Exact operating-system versions, logging configuration, Sysmon configuration,
and other environmental details will be recorded when the lab is deployed.

## Methodology

The experiment will follow the project's standard research methodology:

1. Establish the baseline Windows configuration.
2. Record enabled telemetry sources.
3. Generate controlled PowerShell activity.
4. Collect and preserve relevant telemetry.
5. Analyze resulting Windows and PowerShell events.
6. Enable enhanced PowerShell logging and Sysmon.
7. Repeat the controlled activity.
8. Compare baseline and enhanced telemetry.
9. Identify behavioral detection opportunities.
10. Develop and test detection logic where appropriate.
